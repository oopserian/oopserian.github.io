# eooo.me

Erian 的个人网站：首页只有一屏，是一格一格的一张表，放下简介、已经上线的 SOOTY（海报会动）、直接跑着的三个实验（海浪、晚霞、树）、全部实验的目录、联系方式和全部项目；能直接玩的界面小实验在单独的 `/lab/` 页。在站内换页时一道字符画的海浪冲过来盖住页面、再退下去露出新页面。网站上的字是英文的，代码注释和文档用中文。

![首页](docs/home.png)

## 本地开发

要 Node 22.23.4 以上（Astro 7 的要求，CI 用的是 24）和 pnpm。

```bash
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # 生成 dist/
pnpm preview    # 看 dist/ 的样子
pnpm check      # 类型检查
```

改完用浏览器在 1440 和 390 两种宽度、浅色深色各看一遍：不能有横向滚动条，控制台不能有报错。

## 加一个实验

1. 建目录 `src/labs/<slug>/`，`slug` 就是网址里那段（`/lab/<slug>/`），用小写和短横线。
2. 写 `Demo.tsx`，默认导出一个 React 组件。根元素写 `className="lab-root <自己的类名>"`：`lab-root` 让它撑满舞台、内容居中，颜色、圆角、阴影都从它上面的变量取（见下面「实验的样子」）。舞台在卡片上高 280px，详情页上撑满第一屏剩下的高度（宽 1440、高 900 的窗口里大约 1200×580，手机上 360×500 上下），底色跟着主题走（浅色是浅灰，深色是深灰）；`index.md` 写了 `dark: true` 的，不管主题都是深灰的底，实验里读到的 `color-scheme` 也是深色，就一直按深色那套画。样式写在同目录的 `style.css`，在 `Demo.tsx` 里 `import "./style.css"`，选择器都挂在自己的类名下面（`.folder-lab .front`），不写裸的 `button`、`p`。类名也别跟 Tailwind 的工具类撞（`ring`、`grid`、`hidden`、`flex` 这种）：Tailwind 扫 `src/labs/`，看到就生成，规则会落到你的元素上（Select & Zip 的进度圈起先叫 `.ring`，平白多了一圈白框）。图标从 `../_kit/icons` 拿，要用 WebGL2 画的从 `../_kit/gl.js` 拿样板（建上下文、编着色器、离屏图这些）。图片放 `assets/`，引用写 `import cover from "./assets/cover.webp?url"`（带 `?url` 拿到的是地址；不带的话 Astro 给的是一个对象，`<img src>` 会变成 `[object Object]`）。
3. 写 `index.md`：

   ```md
   ---
   title: Folder
   summary: 卡片和详情页标题下的一句话
   tags: [CSS, SVG]
   date: 2025-01-08         # 做出来的日子：卡片上显示年月（Jan 2025），详情页显示月份全称
   inspiration: https://…   # 照着谁的设计做的，没有就不写
   wip: true                # 还没做完：卡片上画斜条纹，不挂组件，不生成详情页
   dark: true               # 舞台不管浅色深色都是深底。五个 ASCII 实验都开着：细的字在浅灰底上发虚（2026-11-17）
   order: 5                 # 同一天做的按它排，越小越靠前
   prompt: |-               # 详情页上的 Prompt，英文，分段，保留换行（所以是 |-，不是 >-）
     Add a folder to my project that opens and fans out the photos inside when you point at it. …

     0. Start from what exists
     - Find where the folder goes, …

     1. Shapes and colours
     - …

     4. Done when
     - …
     - You tell me every file you added or changed.
   ---
   ```

   只写头，不写正文：详情页舞台下面只放 Prompt（右上角一个拷贝按钮，超过 360px 高先折起来）和源码地址，不放做法说明（2026-11-04 laken 定的）。

   详情页的第一屏是录屏用的一整块（2026-11-04 laken 要的，方便自己录屏）：标题和一句话在框外，1px 细线框起来的舞台撑满一屏剩下的高度，框下一行左边是日期和标签，右边是 X 上的 @oopserian（水印，也是链接）。右上角「Focus」把这一块铺满整个窗口，藏掉顶栏、页脚和下面的东西，四边留白跟分享图一样；地址加上 `?focus`，Esc 或浏览器的后退回来，直接开 `/lab/<slug>/?focus` 也行。录屏时先换好主题再进整窗模式。

   prompt 是给读者拷进自己项目里用的，不是只复刻我们这个 demo（2026-11-04 laken 定，参考了别人那种分步骤的长 prompt）。照现有几个的样子写：开头一两句说要做什么、用什么做、放进「我」现有的框架和设计系统里；`0. Start from what exists` 先让 AI 看项目里已有的组件和设计变量；中间几段按这个实验的门道分（结构、交互、动效、主题、性能和无障碍）；最后 `Done when` 列做完要满足什么，最后一条是「告诉我改了哪些文件」。数字、曲线、时长都照代码写，写之前对一遍。

卡片上的「源码」链接指向 GitHub 上的 `src/labs/<slug>/`，不用另外填。`/lab/` 页的实验排成两列，新做的在前（按 `date`，同一天的按 `order`，2026-11-05 laken 定），首屏的实验目录、详情页的上一个和下一个也按这个顺序；个数是单数时第一张（最新的）占满一行。所以一个实验在 `/lab/` 页上可能是半宽的卡片（桌面上约 600×280、手机上约 360×280），也可能占满一行（约 1200×280），按舞台大小挑排法的实验这几种都要看一眼：2026-11-17 laken 说「有点奇怪」的两处，一是 Paper Attachments 在半宽卡片里还用文件横排的那种，文件压到了对话框底下（现在放不下就换成左边一列小图），二是 Select & Zip 占满一行时窗口贴着顶、底下给操作栏留的空白一大截（现在窗口在整张卡里居中，操作栏出来落在提示那一行上，提示让开）。加完实验跑一遍 `tools/og.mjs`，截它的分享图（见「分享卡片」）。`index.md` 里的标题、一句话和 prompt 照代码实际怎么做的写，改了做法要跟着改。

## 实验的样子

`src/labs/_kit/kit.css` 是实验共用的一套样子，由 `LabDemo.tsx` 引进来；`_kit/icons.tsx` 是实验用的图标。2026-10-27 laken 要把八个实验的样子统一起来，说明了不是改成直角，于是：

- 网站本身是直角、不用阴影；实验是一个个能摸的小组件，留着圆角和很轻的阴影，但只用这几档：圆角 `--lab-r-sm` 8px、`--lab-r-md` 12px、`--lab-r-lg` 16px、`--lab-r-xl` 24px，阴影 `--lab-shadow-1`（贴着）和 `--lab-shadow-2`（浮起来）。
- 颜色都用 `--lab-*` 变量（卡片底 `--lab-surface`、凹下去的 `--lab-sunken`、线 `--lab-line`、字 `--lab-fg` 这些），用 `light-dark()` 跟着网站的浅色深色走，不写死某一种主题的颜色。强调色就是网站的钴蓝 `--lab-accent`，另外只有报错的 `--lab-danger` 和成功的 `--lab-success`。
- 动效曲线用 `--lab-ease`（一般的过渡）和 `--lab-spring`（弹出来，稍微冲过头）。系统开了「减弱动态效果」，`kit.css` 把实验里的过渡和动画都缩到一瞬。
- 鼠标、触屏、键盘都要能玩：悬停才有的效果，触屏上换成点一下；能点的东西用 `button`，或者加上 `role` 和 `tabIndex`。舞台底下一行 `.lab-hint` 告诉人怎么玩，鼠标、触屏玩法不一样就写两句（`.for-mouse`、`.for-touch`），按设备只露一句。按钮用 `.lab-btn`。
- 省：指针移动时不改 React 的状态，位置写进 CSS 变量或者直接写 `transform`；动的只有 `transform`、`opacity`（和 `translate`、`rotate`、`scale` 这几个单独的属性）；一直转的用 CSS 动画，暂停用 `animation-play-state`；`backdrop-filter` 这种贵的层只在用的时候挂上。
- 不用动画库和图标库：原来几个实验的 Motion 动画换成了 CSS 过渡、`@starting-style` 和 Web Animations，Tabler 图标换成了 Phosphor（跟网站一样），这样实验只下载 React 和自己那一小段。要加图标，从 `@phosphor-icons/core` 的 `assets/regular/` 里把 `<path>` 的 `d` 拷进 `icons.tsx`。不经过 React、由脚本自己建的元素（比如 Paper Attachments 里拖进来才有的附件小图）用同一个文件里的 `iconSvg(name, size)` 拿 SVG 字符串。

## 加一个项目

在 `src/content/projects/` 加一个 `.md`，只要 frontmatter：`name`、`summary`（一行）、`kind`（App、Tool、Site 这种）、`status`（可不写）、`url`、`icon`（`src/assets/` 里的图，写相对路径）、`order`、`hidden`（可不写）。

图标要正方形、铺满不留白（四周透明的边裁掉），列表里一律显示成 40px、圆角 27% 的方块，几个图标才一样大。

## 设计约定

- 直角、不用阴影，区块之间用 1px 细线分开。
- 黑白灰为主，略带暖。强调色只有一个钴蓝，只给链接、当前状态（比如首屏实验目录里正放着的那一行）和字符画里被搅动的字：浅色主题 `#2F4BE8`（在底色上对比度 6.0），深色主题 `#8597FF`（7.4）。原来是炭火的橙，2026-10-27 laken 嫌它发黄，换成了蓝。灰的几档都过 4.5。值在 `global.css` 开头，深色写了两处（跟随系统、手动选了深色），改要一起改；手动选了深色那一处同时管 `.always-dark`，就是不管主题都用深色的一块（`dark: true` 的实验舞台）。
- 大标题 Instrument Serif（第二行斜体），标签、日期、导航这些小字 DM Mono，正文用系统字体。两款都是 SIL OFL 1.1，许可证在 `public/fonts/OFL.txt`，文件是从 sooty 官网拷来的拉丁字母子集。字体都放在本站，不从 Google Fonts 拿。Unboxing 的卡面、盒面上的小字另外用 Instrument Sans（可变字重 400–700，`public/fonts/instrument-sans-latin-wght-normal.woff2`，取自 @fontsource-variable/instrument-sans 5.3.0 的拉丁字母子集，也是 OFL），只在这个实验的 `style.css` 里声明，别的页面不下。
- 浅色、深色跟随系统，顶栏右边（首页是简介那格右上角）的按钮可以手动换，记在 `localStorage` 的 `theme` 里；`<head>` 最前面那段脚本在页面画出来之前就定好，不闪。
- 页面上只有淡入和短距离的位移（`.rise`）、首屏标题后面一闪一闪的光标和换页的海浪，系统开了「减弱动态效果」就都不动（海浪不播，直接换页）。一直在动的只有实验（包括首屏上的三个）和首屏 SOOTY 那格的海报，它们自己限帧、看不见就停。

## 换页的海浪

2026-11-17 laken 要「页面过渡就是那个海浪冲刷 UI，可以用浅色和深色两种」（`src/components/WaveTransition.astro`，`Base` 每页都带）。点站内的链接，一道字符画的浪从屏幕底下涌上来把页面盖住（720ms），盖满了才真的换页；新页面打开时先整个是底色，浪再往下退（950ms），退的时候在页面上留一圈沫子，很快散掉。

- 用显卡画：WebGL2，一个盖满屏幕的片元着色器，每个像素算出自己在哪一格、那一格画什么字，从图集里取，每帧只有一次绘制。第一版用 canvas 2D 一格一格贴，大屏高清屏上一帧要贴四万次，laken 说卡，就换了。会随时间变的相位都在 JS 里用双精度算好、取过模再传进去，手机显卡上 sin 也准。
- 画法跟 ASCII Waves 一个路子：整片切成 8px 的格子，每格一笔拉满一格宽的 `-` `~` `=`，左右两格接成一整道。水下是一道往上走的大涌，浪头按 x 弯来弯去，同一道浪头上的字都转到它的走向上；再叠一道细一点的碎浪只改亮度，亮度挑字、挑颜色。浪尖后面一簇簇的浪花用 `. : * o @`，梭子形，一会儿冒出来一会儿散掉；浪头那一道最浓的沫子贴着水面，往上溅几点。不用几道方向差不多的波互相交，那样交出一个个闭合的圈，像布纹不像海。
- 两套颜色跟着当时的主题：浅色是纸上的钴蓝墨，浪越高墨越浓，浪头一道深墨，浪花是留白里淡淡的蓝；深色是深底上的蓝浪，浪花和浪头是白的。水下先整片盖上页面的底色，所以浪是实的，看不见底下的字。
- 字先用 canvas 2D 画进一张图集（三种笔画各转 9 档、五个沫子的字，白的，一个字正好一格大），颜色在着色器里上。只在换页那一两秒里画，画完就把显卡上下文还掉，平时什么都不跑。
- 浪纹用墙上的钟算，换页前后两页的浪接得上。前一页在 `sessionStorage` 里记一下 `wave`，新页面 `<body>` 一开头的小脚本看到了就先给 `<html>` 加 `data-wave`，用底色盖住整页，等浪接手；五秒以前的记号不算。新页面上浪先在原地翻着，等 `load`（最多 300ms）再退，免得跟页面自己的初始化（实验的脚本、React）抢着卡。
- 不播：系统开了「减弱动态效果」，没有 WebGL2 或者显卡是软件模拟的（直接换页），按着 Cmd、Ctrl、Shift、Alt 点，`target` 是新窗口，`download`，站外链接，只换 `#` 的链接，图片和文件，写了 `data-no-wave` 的链接。无头浏览器是软件渲染，测的时候先设 `window.__waveSoftwareOk = true`。
- 网慢就一直盖着等，浪在原地翻；过了 15 秒还在这一页（换页被拦了之类）才退回去。第一版是 4 秒，网慢时浪先退回旧页面、过一会儿又换页；而且页面进了后退缓存，这个计时器会冻住，后退回来接着走，浪过一会儿自己冒出来（laken 说「莫名其妙的出现」）。现在 `pagehide` 时清掉计时器；后退、前进从缓存里拿回来的页面停在盖满的那一帧，浪接着退下去，像刚到一样。

## 选型

- **Astro**（静态生成）：比较过留在 Vite + React 单页、Next.js 静态导出、Eleventy。原来的单页把所有东西都放在一个 JS 里，HTML 是空的，搜索引擎和分享卡片都看不到内容，首屏要等 React 下载完；Next.js 静态导出每页都带着 React 的运行时；Eleventy 页面很轻，但实验是 React 组件，要另想办法挂。Astro 默认页面不带 JS，又能把 React 组件当「岛」按需挂，正好：页面本身只有主题按钮、复制邮箱、换页的海浪几段小脚本，React 和实验的代码等实验快进屏幕才下载（首屏上放着三个实验，所以首页一打开就下这三个），一个实验一个文件。sooty 的官网也是 Astro，用法一样。
- **React 只给实验用**：实验原来就是 React 写的，拖动、切换这些交互用 React 写也顺手，源码公开给人看。2026-10-27 重写时样式换成了普通 CSS 和共用的 `_kit/kit.css`，去掉了 Motion、Tabler 图标和 Tailwind 的类名（见「实验的样子」）。网站本身（顶栏、首页、实验页、详情页）全是 Astro 组件和普通 CSS。
- **Tailwind 只扫 `src/labs/`**：现在的实验都不用它的类名，留着主要是 preflight 当整站的样式重置；以后的实验想用类名也能用。网站自己的样式不用 Tailwind，写在组件的 `<style>` 里。
- **ASCII Waves、ASCII Clouds、ASCII Coal、ASCII Sand、ASCII Black Hole 直接写 WebGL2，不引 3D 库**：五个实验都是着色器在离屏图里画一个真的 3D 场景当底稿（海：透视镜头、12 万个点的海面网格、深度；云：往天上打光线，在云层里一步步走；煤：斜着往下看一床煤块，按 Voronoi 分成一块块，每块的高度连同坡度一起算，光线步进只在尺寸变了时算一次、存下落点，每帧只重新打光，2026-11-05 照 laken 给的一块裂开的煤的图加的；沙：站在沙丘上往地平线看，每个像素往高度场打光线，迎风坡缓、背风坡陡，迎风坡上有沙纹，低低的太阳往太阳那边走几步算影子，2026-11-06 加的；黑洞：每个像素的光线按史瓦西黑洞的引力一步步弯着走，穿过吸积盘就加上盘在那儿的光，盘后面那一半被弯到黑洞上下成两道光环，2026-11-09 laken 要一个宇宙题材的，挑了黑洞），再全屏挑字，屏上只有字。五个实验挑字的做法一样：- ~ = 这类横的字转到浪头、沙纹、煤面等高线、气体绕着转的走向上，明暗主要靠颜色。格子 5px 见方，横的字连描边一起拉到正好一格宽，左右两格首尾相接连成一整道（原来是 8px、拉到八成多宽，一段段断开的；2026-11-17 laken 嫌浅色背景上看不清，要格子密一点、铺满，6px 和 5px 比过以后选了 5px）。黑洞的光线是弯的，字的方向没法从盘面直接投到屏幕上，改成按屏幕上「穿过盘面那一点的半径」的导数算，绕到黑洞上面的光环上字也跟着绕。煤和沙第一版是正对着、从正上方看的，缝和棱用不转的 ~ - \ | / 描（老式字符画的做法），laken 觉得跟海和云比差太多，2026-11-06 都改成了现在的透视镜头和转着的字。2026-11-04 先用 Three.js 写了海浪（laken 定的「全程用 Three.js 和 shader 实时渲染」），同一天做云的时候 laken 觉得不用 Three.js 也能一模一样，定了两个实验都改成原生 WebGL2。着色器本来就是自己写的，Three.js 只替我们做了镜头矩阵、离屏图、深度、mipmap 和「鼠标落在海面哪里」，这些在 `src/labs/_kit/gl.js`（建上下文、编着色器、按类型设 uniform、全屏三角形、离屏图、从 canvas 建贴图）和 `waves.js` 开头的两个矩阵函数里，一共一百多行。改完以后海浪的静止帧跟 Three.js 那版逐像素一样（深浅两种主题、1 倍和 2 倍屏都比过），海浪这个实验少下 540 KB（gzip 后 135 KB）。也看过：
  - Three.js（0.186，MIT）：`PerspectiveCamera`、`RawShaderMaterial`、`WebGLRenderTarget`、`Raycaster` 正好都有，但只用到这几样，场景树、材质、灯光这些大半的代码用不上，却要整个下载。
  - OGL（1.0，Unlicense）：小，接口跟 Three.js 像，但 2025 年初以后没再发版。
  - regl（2.1，MIT）：函数式的写法很省，但只支持 WebGL1，着色器得改写成 GLSL 1.0，2024 年以后没再发版。
- **Crown Shyness 用 CPU 一个像素一个像素地画，不用 WebGL**：画面就是一张约 3.6 万个像素的小图（放大几倍按舞台面积定），再整数倍放大；每个像素要知道归哪棵树、离缝多远、被哪一团叶子盖住、落在色带的哪一档，在 JS 里扫几遍数组最直接，颜色也能一档一档地管住（像素画靠的就是这个）。写成着色器的话，叶团、主枝、近处的叶团这种按先后叠的东西得拆成好几遍渲染，省不了多少。无头 Chromium 里（没有显卡）一帧二十毫秒上下，平时限 30 帧，滚出屏幕就停。2026-11-12 先做成发帖用的单页（照 laken 给的一张林冠照片，像素风参考 feralui.dev/pixel-play），11-13 放进 lab 时把「按宽度排林子、一行一百八十像素」改成按面积：详情页的舞台又宽又矮，按宽度排的话树冠被放得很大、像素也粗。
- **Paper Attachments 直接写 WebGL2，纸的物理在 CPU 上算，不引 Three.js 和物理库**：拿起来的纸是一张 13 列的网格，用 Verlet 积分加距离约束（相邻、对角，再加隔 2、4、8 格的长约束给它纸的硬度），每步再做一次形状匹配，弯得宽而顺、不会在一行上折死；手捏住的是纸宽 17% 的一小块圆，手每步带着纸走七成，快速一甩会摆，但不会皱成一团。一张纸两百来个点（提案是 13 × 18），无头 Chromium 里一帧（两步）算半毫秒左右，写成着色器反而要来回倒数据。画的部分是透视镜头、一张带法线和折角的网格、一张离屏影子图（主光影子按高度往右下滑、贴着纸的环境影子，横竖各模糊一遍），杂活还是 `_kit/gl.js` 那几样，透视矩阵自己写。2026-11-16 先做成发帖用的单页，那一版用的是 Three.js（r128）；放进 lab 时改成原生 WebGL2，省掉这一个实验要下的 Three.js。桌上的小图、附件、发出去的页都是普通的 DOM，只有纸在空中时画布才画，落定了就停；没有 WebGL2 时换成扁平的卡片走同样的路线。
- **Select & Zip 的操作栏用 clip-path 变形**：跟着指针的计数是一颗 24px 的小药丸，松手飞下去长成 336px 宽的整条，两样其实是同一个元素：它一直是整条那么大，用 `transform` 挪位置，用 `clip-path: inset(… round …)` 从中间露出一块圆角矩形，位置、宽、高三个弹簧每帧推一步，松手时直接换目标，药丸带着指针的惯性冲进栏里，不是重新起步。比较过直接过渡 `width`、`height`（Files in Motion 单页那一版就这么写的）：每帧都要重排，也不合「动的只有 transform 和 opacity」的约定；CSS 过渡中途换目标会断掉速度。被裁掉的 `box-shadow` 换成外面一层的 `drop-shadow`。文件飞进按钮、压缩包飞出来是复制一份图标沿二次贝塞尔弧飞，原来的那个在网格里先藏着；网格里的挪位用 CSS 过渡 `transform`。
- **Descent 直接写 WebGL2，整个画面是一个全屏片元着色器**：从轨道一路落到一千米深，画面里的东西都靠每个像素往场景里打光线算：大气照 Hillaire 2020 的做法，透射率、多次散射、天空辐照度三张查找表开头画一次，每个像素沿视线积分；云是 1 到 3.6 千米的一层，形状来自开头在显卡上生成的 128³ Perlin-Worley 噪声，远处的云量看卫星云图，下坠点附近是设计过的积云场（朝太阳方向留一道缝伸到特内里费岛，贴着海面也看得见泰德峰）；海浪是 7 组涌浪加 25 组在 24 米上平铺的短浪（焦散图按这个周期画）；群岛的地形是真的高程图，光线在 0 到 3.8 千米的壳里求交；水下有吸收、散射、焦散、斯涅尔窗。2026-11-17 先做成发帖用的单页，laken 说「做进我的博客」以后搬进来：着色器原样搬（`shaders.js`），引擎改成按舞台大小画、限帧、滚出屏幕就停（规矩写在 `engine.js` 开头），仪表和按钮换成 React 加 kit 的样子。没用 Three.js：整个画面不是一堆网格，是几遍全屏的着色器，Three.js 的场景树、材质、灯光都用不上。也没用 `_kit/gl.js` 的离屏图：这里要半浮点的离屏图、3D 贴图、单通道的数据图，引擎开头自己写了几行。
  - 贴图：地表 4096 × 2048、云图 4096 × 2048、夜光和水陆遮罩 2048 × 1024、加那利群岛高程 2048 × 768（无损），都转成 WebP；舞台窄于 700px（卡片、手机）时地表和云图改下 2048 宽的，一共约 0.75 MB，详情页约 1.8 MB。来源：地表和夜光是 NASA 的 Blue Marble、Earth at Night，云图是 Tom Patterson 的 Natural Earth III（经 three-globe、globe.gl 的示例图），都是公有领域；高程来自 AWS Terrain Tiles（SRTM、GMTED、ETOPO1 等，含 EU-DEM 的部分按要求注明：Produced using Copernicus data and information funded by the European Union - EU-DEM layers）。
  - 没有显卡（软件渲染）时不画：这个着色器在 CPU 上画一帧要几分钟，换成一张事先渲好的静帧 `assets/poster.webp`（4.9 千米的积云和泰德峰，1600 × 800，用同一套着色器在单页上渲的），仪表停在它的高度；分享图截的就是它。没有 WebGL2、着色器编不过、上下文丢了也一样。
  - 无头浏览器里要跑真引擎自查，在页面脚本之前把 `getParameter` 拿到的显卡名字改成假的（`RENDERER`、`UNMASKED_RENDERER_WEBGL` 返回别的字符串），软件渲染的判断就过去了；很慢，舞台小一点、开「减弱动态效果」让进度直接跳到位。
- **Unboxing 用 Three.js（0.169，MIT），是实验里唯一引 3D 库的**：前面几个不引，是因为画面是几遍全屏着色器，Three.js 的场景树、材质、灯光都用不上；开盒正好反过来，用的就是这些：一棵嵌套的场景树（盒盖绕铰链转、“手”这一组始终正对相机、卡从卡包里交到手上要保留世界位置），带清漆、sheen、粗糙度金属度贴图和法线图的 PBR 材质（卡面镭射是在它的着色器里 `onBeforeCompile` 插一段），RoomEnvironment 经 PMREM 做的环境光，VSM 软影子，`ExtrudeGeometry` 挖出凹槽和半圆指口的内托，还有对几十个网格的射线拾取。这些自己写要几千行，也很难写得比它对。只有这个实验下它：实验按 `client:visible` 一个个按需挂，进屏幕才下载：这个实验的脚本连 Three.js 一共 590 KB，gzip 后 158 KB，别的页面不受影响。版本停在 0.169.0，因为 2026-11-17 先做成发帖用的单页时就是在这个版本上调的灯光和材质。贴图都是开头在 canvas 上画的（盒面印刷、纸纹、锡箔褶皱、五张卡），不下图片；卡面一张要画一两百毫秒，所以先贴一个像素，空闲时一张张画好换上，撕开卡包时没画完的当场画完。纸带（撕拉条、卡包撕条）是自己写的两排质点加距离约束。没有显卡时放四张事先渲好的透明底静帧（宽舞台一排、窄舞台两排，浅色深色各一张），用无头浏览器加 SwiftShader 跑真引擎，摊开五张卡后从画布 `toDataURL` 存下来再转成 WebP。
- **分享图用 Playwright 截**（1.63，Apache-2.0，只是开发时用的依赖，不进页面）：实验的样子就是页面本身，截真页面最准，也不用另写一套画图的代码。比较过 Satori（Vercel 的 JSX 转 SVG，MIT）：画标题和字很方便，但画不了实验本身（WebGL、CSS 3D、背景模糊都不支持），只能放一张事先截好的图进去，等于还是要截图；Astro 的 `astro:assets` 只能处理已有的图，不能截图。
- **图标**：Phosphor 的 regular 粗细，几个用到的直接写成内联 SVG（网站的在 `components/Icon.astro`，实验的在 `src/labs/_kit/icons.tsx`），不引图标库。

## 部署

推到 `main` 以后 `.github/workflows/deploy.yml` 用 Node 24 和 pnpm 构建，把 `dist/` 发到 `gh-pages` 分支，GitHub Pages 从那个分支发布到 eooo.me（`public/CNAME`）。`public/.nojekyll` 让 GitHub Pages 不走 Jekyll，不然 `_astro/` 这种下划线开头的目录会被丢掉。
